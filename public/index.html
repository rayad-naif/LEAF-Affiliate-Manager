CRM Custom Fields

Create the Leads This Week and Total Earned contact fields in your CRM. Once created, you can build CRM workflows that trigger on field-value-changed and send email notifications to your account admin automatically.

How it works:

1. Click Create Custom Fields below — this adds two Number fields to every contact in your CRM location.

2. In your CRM, create a workflow with trigger Contact field value changed → filter for Leads This Week or Total Earned.

3. Add a Send Email action to notify the account admin whenever these values update each week.

Subscription Renewal Tracker

Pulls all subscriptions from GHL, identifies which are affiliated, and checks each one 2 days after its renewal date to confirm it's still active. Affiliated subscribers earn the affiliate a recurring commission each cycle. Cancelled subscriptions stop automatically.

How it works:

1. Subscriptions & transactions are synced automatically (on load, then every 5 min) and matched to your affiliates — Sync Subscriptions below is only needed for an immediate manual refresh.

2. The system checks each affiliated subscription 2 days after each billing renewal date.

3. If renewed → affiliate earns commission and next check is scheduled. If cancelled → tracking stops automatically.

4. Use Run Check Now anytime to immediately process all due subscriptions.
